# Axioma WMS — მოკლე სახელმძღვანელო

## 1. ინსტალაცია
1. გაუშვით ფაილი **Axioma WMS Setup 1.3.1.exe**.
2. თუ Windows აჩვენებს „Windows protected your PC“ — დააჭირეთ **More info → Run anyway** (პროგრამა ციფრული ხელმოწერის გარეშეა).
3. აირჩიეთ ინსტალაციის საქაღალდე → **Install**. სამუშაო მაგიდაზე გაჩნდება ხატულა **Axioma WMS**.

ინტერნეტი არ არის საჭირო. ყველა მონაცემი ინახება ამ კომპიუტერზე.

## 2. პირველი გაშვება
1. შეავსეთ კომპანიის დასახელება (ჩანს PDF ფორმებზე), ს/კ, მისამართი, სურვილისამებრ ლოგო → **დაწყება**.
2. მთავარ ეკრანზე „დაწყება“ ბლოკში შეასრულეთ ნაბიჯები:
   - **პროდუქტების და ნაშთის იმპორტი** — ერთი CSV ფაილით (ან ხელით „პროდუქტები“ გვერდზე)
   - **ტექნიკის იმპორტი** — CSV ფაილიდან
   - **სარეზერვო საქაღალდე** — აირჩიეთ საქაღალდე USB-ზე ან გარე SSD-ზე
3. სურვილისამებრ: **შესაბამისობა (VIN × არტიკული)** — რომელი ნაწილი რომელ ტექნიკაზე ყენდება.

### CSV ფაილის მომზადება
- იმპორტის ფანჯარაში დააჭირეთ **შაბლონი** — შეინახება ფაილი სწორი სვეტებით.
- შეავსეთ Excel-ში და შეინახეთ: **ფაილი → შენახვა როგორც → CSV UTF-8**.
- სვეტებს პროგრამა **სათაურით ცნობს**, ამიტომ მათი მიმდევრობა მნიშვნელოვანი არ არის (ძველი შაბლონებიც მუშაობს).
- იმპორტამდე პროგრამა აჩვენებს თითოეულ სტრიქონს: **ახალი / განახლდება (რა შეიცვლება) / უცვლელი / შეცდომა**. შეცდომიანი სტრიქონები გამოტოვდება.

**პროდუქტები და ნაშთი** — სვეტები: არტიკული; დასახელება; ზომის ერთეული; მინ. ნაშთი; რაოდენობა; ღირებულება; ლოკაცია; საწყობი
- ახალი არტიკული → იქმნება პროდუქტი ნაშთით, ფასით და ლოკაციით.
- არსებული არტიკული → **ცარიელი უჯრა = არ შეიცვალოს**; შევსებული რაოდენობა ჩაანაცვლებს ნაშთს. მაგ. ფაილი მხოლოდ არტიკულით და რაოდენობით ანახლებს მხოლოდ ნაშთს.
- საწყობი: 1 ან 2 (ცარიელი = 1). ერთი არტიკული ორ სტრიქონზე შეიძლება, თუ საწყობი განსხვავდება.

**შესაბამისობა (VIN × არტიკული)** — მატრიცა: პირველი სვეტი VIN, დანარჩენი სვეტების სათაური — არტიკული; უჯრაში **1 / x / ✓ / +** ნიშნავს, რომ ნაწილი ამ ტექნიკაზე ყენდება.
- „შაბლონი“ ჩამოტვირთავს მზა მატრიცას: ყველა ტექნიკა × ყველა არტიკული, არსებული კავშირები მონიშნულია. მონიშნეთ Excel-ში და შემოიტანეთ.
- სვეტები „სახ. ნომერი“ და „მოდელი“ მხოლოდ საორიენტაციოა და იგნორირდება.
- ჩვეულებრივ იმპორტი **მხოლოდ ამატებს** კავშირებს. „ჩანაცვლება“ ფაილის VIN-ებზე ძველ კავშირებს წაშლის და დატოვებს მხოლოდ მონიშნულს.
- **კატალოგი** აჯგუფებს ტექნიკას მარკის, მოდელის და წლის მიხედვით (მაგ. JCB 3CX 2020). კატალოგის გვერდზე აირჩიეთ მარკა და მოდელი — სვეტებად გამოჩნდება მისი წლები (ერთდროულად მაქსიმუმ 20, ‹ › ღილაკებით გადართვა).
- სერვის ორდერში ამ VIN-ის ნაწილები რეკომენდაციაში პირველია (ნიშანი **VIN**); ტექნიკის გვერდზე შეგიძლიათ ნაწილი ხელით მიაბათ ან მოხსნათ.

## 3. ყოველდღიური მუშაობა
- **შესყიდვა:** „შესყიდვის ორდერები“ → ახალი → მომწოდებელი, პროდუქტები, რაოდენობა, ფასი → შენახვა. მარაგი მაშინვე იზრდება.
- **სერვის ორდერი:** ზედა ღილაკი „სერვის ორდერი“ → ტექნიკის ძებნა ნომრით ან VIN-ით → პასუხისმგებელი პირი → გახსნა.
  - ნაწილის გაცემა: აკრიფეთ არტიკული ან დასახელება → რაოდენობა → **გაცემა** (ან რეკომენდაციიდან).
  - დაბრუნება: ხაზზე **დაბრუნება**.
  - მომსახურება: დასახელება თავისუფლად, ფასი არასავალდებულოა.
  - ორდერი იხურება ხელით ან ავტომატურად — ბოლო ცვლილებიდან 7 დღეში. დახურული ორდერის გახსნა შესაძლებელია.
  - **PDF ფორმა** → **PDF-ად შენახვა** — A4 ფორმა ხელმოწერის ველებით.
- **ნაშთზე მეტის გაცემა შეუძლებელია** — პროგრამა არ დაუშვებს უარყოფით ნაშთს.
- **სერიული ნომერი** (არასავალდებულო): გაცემისას ჩაწერეთ ველში „სერიული №“ (რამდენიმე — მძიმით), ან მოგვიანებით ხაზზე **S/N**. დაბრუნებისას მონიშნეთ, რომელი სერიული ნომერი ბრუნდება. ზედა ძებნაში სერიული ნომრით იპოვით, რომელ მანქანაზე დაყენდა.

## 3ა. ლოკაციები
- **საწყობი და ლოკაციები** → **ახალი ლოკაცია** ან **სიით დამატება** (ჩასვით კოდები, თითო სტრიქონზე ერთი — მაგ. Excel-ის სვეტიდან).
- კოდი თავისუფალია: A-01-02, ZONE-3, გარე საწყობი… დაამატეთ აღწერა, საჭიროებისას გამორთეთ.
- პროდუქტს ენიჭება მხოლოდ სიაში არსებული აქტიური ლოკაცია. გადარქმევისას პროდუქტები ახალ კოდზე გადადის; წაშლა — მხოლოდ ცარიელის.
- CSV იმპორტისას უცნობი ლოკაცია ავტომატურად დაემატება სიას.

## 4. სარეზერვო ასლი
- ასლი იქმნება **ავტომატურად პროგრამის დახურვისას**, თუ USB / SSD მიერთებულია და მონაცემები შეიცვალა.
- ხელით: **პარამეტრები → სარეზერვო ასლი → ასლის შექმნა**.
- გარე დისკი შეინახეთ კომპიუტერისგან ცალკე.
- აღდგენა: **პარამეტრები → აღდგენა** → აირჩიეთ ასლი. აღდგენამდე მიმდინარე მდგომარეობა ავტომატურად ინახება.

## 5. განახლება
ახალი ვერსიის Setup.exe-ს გაშვება ინახავს ყველა მონაცემს. განახლებამდე რეკომენდებულია სარეზერვო ასლის შექმნა.

## 6. პრობლემის შემთხვევაში
**პარამეტრები → პროგრამის შესახებ → საქაღალდის გახსნა** — აქ არის ბაზა (`axioma-wms.db`; Belo WMS-იდან განახლებულ ინსტალაციაზე — `belo-wms.db`) და ჟურნალი (`logs\app.log`). ჟურნალი გაუგზავნეთ მხარდაჭერას.
